# Решись Авиа — Сервис динамического ценообразования

Веб-приложение (Frontend + Backend API) для прогнозирования пассажирского спроса на авиабилеты при изменении стоимости перелёта. Сервис помогает менеджерам авиакомпании «Решись Авиа» оценивать ожидаемую загрузку рейсов по медианному прогнозу и 9 квантильным сценариям.

## Основной функционал

* **Расчёт спроса и продаж по медиане (`0.5`):** вычисляет потенциальное число желающих пассажиров и фактический объём продаж с учётом предельной вместимости воздушного судна (`seats`).
* **Квантильный анализ (`0.1`–`0.9`):** строит интерактивную столбчатую диаграмму распределения спроса по всем 9 сценариям с визуальной отметкой вместимости самолёта.
* **Регистрация и авторизация:** разграничение доступа пользователей с хранением учётных записей и токенов сессий в базе данных SQLite (`users.db`).
* **Минималистичный тёмный интерфейс:** одностраничный веб-клиент без тяжёлых внешних зависимостей с отрисовкой графиков на встроенном HTML5 `<canvas>`.

---

## Математическая модель

Для выбранного маршрута, даты вылета и цены билета расчёт выполняется по формулам:

\[\text{Желают}_X = X\_\text{base\_demand} - \text{price\_sensitivity} \times (\text{Цена} - \text{base\_price})\]

\[\text{Купят} = \min\Big(\text{seats},\ \max(0,\ \text{Желают}_{0.5})\Big)\]

Где:
* \(X \in \{0.1, 0.2, \dots, 0.9\}\) — квантиль базового спроса из таблицы прогнозов;
* `base_price` и `price_sensitivity` — базовая цена и коэффициент ценовой чувствительности маршрута;
* `seats` — количество пассажирских кресел на рейсе.

## Локальный запуск

1. **Клонируйте репозиторий и перейдите в директорию проекта:**
   ```bash
   git clone <URL_вашего_репозитория>
   cd reshis_avia_app
   ```

2. **Установите зависимости:**
   ```bash
   python -m pip install -r requirements.txt
   ```

3. **Запустите сервер:**
   ```bash
   python -m uvicorn main:app --reload
   ```

4. **Откройте приложение в браузере:**
   Перейдите по адресу `http://127.0.0.1:8000`, зарегистрируйте учётную запись на вкладке **«Регистрация»**, выполните вход и рассчитайте прогноз спроса для выбранного рейса.
